# Open in VS Code

1. Extract this ZIP.
2. Open the extracted `Vc-Manegment` folder in VS Code.
3. Terminal 1: `cd backend && npm install && npm start`
4. Terminal 2: `cd frontend && npm install && npm run dev`
5. Open the Vite URL.
6. Login with `admin@vcmanagement.com` / `admin123`.

All business data starts empty.
