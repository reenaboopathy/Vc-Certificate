# Open in VS Code

1. Extract the ZIP.
2. Open the `Vc-Manegment` folder in VS Code.
3. Start MongoDB locally, or use MongoDB Atlas.
4. Backend terminal:

```bash
cd backend
npm install
npm run dev
```

5. Frontend terminal:

```bash
cd frontend
npm install
npm run dev
```

6. Open the Vite URL shown in the terminal, normally `http://localhost:5173/`.
7. Login with:

- Email: `admin@vcmanagement.com`
- Password: `admin123`

Business records start empty. The backend bootstraps the Admin account when MongoDB is empty.
